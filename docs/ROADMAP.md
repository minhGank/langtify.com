# Roadmap

## Phase 1 — completed foundation

Expo/Router, TypeScript, npm, four placeholder tabs, shared UI, ESLint, Prettier,
Jest, documentation, and Langtify naming.

## Phase 2 — current implementation scope

Supabase schema/RLS and language seed; email/password signup/sign-in/sign-out;
persisted auth and guarded navigation; atomic onboarding and profile summary;
validation/session/navigation tests and database ownership checks where runnable.
Supabase provisioning, environment setup, email delivery and real phone checks
are part of the manual integration handoff. No hosted project is assumed.

## Phase 3 and later — not started

Vocabulary and daily assignments, followed by other explicitly scoped product
work. Confirmed slot/replacement/streak/visibility/rating rules are recorded in
PRODUCT.md. They do not authorize implementation in Phase 2. Camera, uploads,
buckets, community features, notifications and moderation remain out of scope.
OAuth providers, password recovery UX, final branding assets, release identifiers,
signing, device validation and store configuration need separate release planning.
